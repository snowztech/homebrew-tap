# snowztech Homebrew tap

Casks for snowztech apps.

## Farol

[Farol](https://farol.sh) is a macOS terminal for working with coding agents. It needs a Mac with Apple Silicon and macOS 14 or later.

```sh
brew install --cask snowztech/tap/farol
```

To update it later:

```sh
brew upgrade --cask farol
```
